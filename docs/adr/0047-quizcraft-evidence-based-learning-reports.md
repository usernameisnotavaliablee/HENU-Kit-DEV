# QuizCraft 拥有基于证据的会员学习报告

用户在 2026-09-29 授权按根 PLAN.md 开始本地实施，不代表生产发布、资料使用权、人工审核或模型传输已获验证。本 ADR 待工程审核；新路径默认关闭。

## 决定

QuizCraft 独占题目、评分、作答和学习数据，新增知识点/能力题型标签、证据快照、报告、审核讲解、后台任务。旧题库 mastery 不改义。报告不是已有错题举报 feedback，采用独立 learning-reports 命名。

后端计算可重建事实；LLM 根据最小必要脱敏证据归纳判断，不能自报统计或猜测没有记录的解题过程。校验结构、引用、归属和版本不能证明推断正确，需要人工评测。证据不足可建议自愿诊断，不能断言薄弱。讲解离线生成、人工审核后组合，练习只选现有合格题。

Portal 沿用 Gateway Practice 通道。Gateway 从验证 session 取得 actor 并核验 lifetime；QuizCraft worker 通过受限签名服务请求向 Account Portfolio 重新核验，不跨库。依赖失败、撤销权益、关闭同意均 fail closed；旧刷题不受影响。不得复用 Career 会员提示文案。

使用 QuizCraft 自有 PostgreSQL 任务与独立 worker，不复用 Mock AI worker 或举报 outbox 表。自动/手动共用链路；租约、失效代次和幂等发布防重复/迟到写回。模型在事务外调用；可能重试外部请求，但同一任务只发布一次。删除先使在途任务失效，不删作答事实。

默认每 7 天，可调 1–30 整天；手动不重置周期、不扣积分、不设日常额度。相同证据及内容/模型/策略版本复用有效结果；运维保护只限制滥用和全局异常成本。

## 兼容与发布

本功能是旧 V1 非目标之外的新迭代，不回写旧规格的历史承诺。增量迁移不更改评分/学习状态；新端点在门禁关闭时不可用。沿用契约生成器。内容审核、真实模型评测、权限/恢复测试和生产授权缺一不可；仅单测或 mock 不算发布证据。

## 不采用

不建新身份/会员系统、向量数据库、多 Agent、自动出题或代码沙箱；不把答对率当能力概率，不因工程实现存在而假定审核完成。
