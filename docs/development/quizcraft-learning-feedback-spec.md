## 不可破坏的断言

1. 真实作答只计一次；同题重做不是多个独立题目。
2. 统计由后端确定；模型只引用当前用户/课程/题目版本的受控证据。
3. 缺资料、缺题、缺审核、证据不足必须诚实展示，不能虚构内容或确定判断。
4. 关闭同意/撤销会员后不得生成或发布；依赖失败不放行；清除后在途结果不能写回。
5. 手动不扣积分、不设日常额度；限流/全局熔断不是配额。
6. 关闭功能后原登录/游客刷题、评分、统计和状态仍按旧契约工作。
7. 三轴审查及真实人工门禁未完成，不记为可发布。

## 验证与留痕

每个实现先写失败用例，再最小实现并检查。环境不能运行时保留用例，记录阻塞；静态检查不冒充运行通过。每次大操作在 HANDOFF 追加范围、命令/结果、下一步及未完成项。

## 已实现的证据快照边界

- `Service.BuildLearningEvidence` 从服务端偏好读取目标/章节；要求当前课程目录启用、内容已审核、题库已发布、用户已主动同意。真实会员校验仍必须由入口与后台执行层负责，不能把本方法当公开鉴权接口。
- 在短 `REPEATABLE READ READ ONLY` 事务中固定目录、偏好与作答事实。按当前题目版本聚合整个有效历史；仅题库版本变化而题目版本不变时保留历史，变更/撤回题目不继承旧结论。
- 分开记录作答数、独立题数、首答正确、重答次数/正确和最近正确；多标签可共享一题，不能把各标签计数简单相加当总题数。不改旧 mastery 定义。
- 首答/最近答案以作答时间及不可变 ID 确定，样本最多 24 个且跨标签去重；优先保留错误样本并轮流覆盖标签，不把有界样本当全量题目或能力概率。
- 指纹包含所有范围内题目的聚合、代表作答和相关版本，不包含单独变化的墙钟截止时间。最终任务键还须绑定模型、提示词和判定策略版本；用户隔离由任务唯一键负责。
- 快照不是外部模型 payload：虽没有账户字段，原作答自由文本仍可能含身份信息。后续适配层必须使用单独的最小化白名单，不能直接发送快照。
