## 不可破坏的断言

1. 真实作答只计一次；同题重做不是多个独立题目。
2. 统计由后端确定；模型只引用当前用户/课程/题目版本的受控证据。
3. 缺资料、缺题、缺审核、证据不足必须诚实展示，不能虚构内容或确定判断。
4. 关闭同意/撤销会员后不得生成或发布；依赖失败不放行；清除后在途结果不能写回。
5. 手动不扣积分、不设日常额度；限流/全局熔断不是配额。
6. 关闭功能后原登录/游客刷题、评分、统计和状态仍按旧契约工作。
7. 三轴审查及真实人工门禁未完成，不记为可发布。

## 验证与留痕

每个实现先写失败用例，再最小实现并检查。环境不能运行时保留用例，记录阻塞；静态检查不冒充运行通过。每次大操作在 HANDOFF 追加范围、命令/结果、下一步及未完成项。

## 已实现的证据快照边界

- `Service.BuildLearningEvidence` 从服务端偏好读取目标/章节；要求当前课程目录启用、内容已审核、题库已发布、用户已主动同意。真实会员校验仍必须由入口与后台执行层负责，不能把本方法当公开鉴权接口。
- 在短 `REPEATABLE READ READ ONLY` 事务中固定目录、偏好与作答事实。按当前题目版本聚合整个有效历史；仅题库版本变化而题目版本不变时保留历史，变更/撤回题目不继承旧结论。
- 分开记录作答数、独立题数、首答正确、重答次数/正确和最近正确；多标签可共享一题，不能把各标签计数简单相加当总题数。不改旧 mastery 定义。
- 首答/最近答案以作答时间及不可变 ID 确定，样本最多 24 个且跨标签去重；优先保留错误样本并轮流覆盖标签，不把有界样本当全量题目或能力概率。
- 指纹包含所有范围内题目的聚合、代表作答和相关版本，不包含单独变化的墙钟截止时间。最终任务键还须绑定模型、提示词和判定策略版本；用户隔离由任务唯一键负责。
- 快照不是外部模型 payload：虽没有账户字段，原作答自由文本仍可能含身份信息。后续适配层必须使用单独的最小化白名单，不能直接发送快照。
- 构建资源门禁：当前题干/选项合计上限 16 MiB，单条首答/最近答案 JSON 上限 4 KiB，内部快照 JSON 上限 1 MiB；超限明确失败，不静默截断或改变原始作答。统计先只读取长度/聚合，再在同一只读事务内只取最多 24 条样本的有界答案；非样本答案不进入指纹或任务快照。大课程零历史不构造模型请求，但仍校验内容完整性与内部快照上限。以上为资源安全上限，并非测量或产品承诺。

## 模型与报告组合的已实现边界

- 内部快照升级 `learning-evidence-v2`：仅为有界样本附题型/选项上下文，每标签最多保留 5 道当前范围内的已有练习，优先未作答题。原评分与作答不改；历史异常 `expected_answer: null` 不进入评价统计。标准导入本来就拒绝缺答案，此过滤是历史异常防护，不声称现网存在该问题。
- `BuildLearningModelInput` 是外发白名单：课程标签、统计和必要题目样本；不含账户、数据库题目/课程 UUID、作答时间、完整历史、资料权限记录或任务快照。样本使用局部题目编号；闭合答案复用已有评分归一化，自由文本及无法安全归一化的用户答案不外发。题干/选项仍须作为不可信数据处理。
- 输入上限 128 KiB，响应上限 32 KiB；超限拒绝，不静默裁剪成另一份证据。模型只能返回最多三项标签、支持状态、当前证据引用、可选假设与一个首要标签；不能返回统计、讲解、题目 ID 或执行动作。
- `ValidateLearningModelDecision` 校验内容摘要、题目版本、标签/证据归属、去重、样本数量及状态。支持性薄弱项暂要求至少 3 道独立题、引用至少 2 道不同题的错误证据；这只是保守实施默认值，不是能力概率或已完成的教育测量标定。人审校准仍阻止发布。
- 观察文案和统计数字由服务器产生。模型假设必须显式以“可能”开头，不接受数值字面量或百分号；这些结构/词法规则不证明自然语言推断正确，也不保证排除所有隐含数字或确定式误导，必须由真实语义评测验收。
- `ComposeLearningReport` 只复用绑定审核内容包中的讲解和当前候选题。来源路径＋定位须满足 API 的 500 字符限制。缺讲解/缺练习明确说明，未知候选题拒绝；仅有已作答单题时明确重做不能增加独立样本。
- 零历史不调用模型、不虚构薄弱点，可给可跳过的已有诊断题。组合函数不发布结果；发布前仍须重新验证会员、同意代次、租约及当前内容。真实供应商、任务、HTTP 和界面尚未接线，不能把合成模型响应当作真实评测。

全量 Go 集成测试含固定 ID/幂等键夹具，需要每次新建空白数据库，按 `tests/main_test.go` 两遍应用 up 迁移后运行；不能复用已经完整跑过的持久测试库并将固定夹具冲突误判为代码回归。学习反馈定向用例会自行创建隔离数据库。

## 偏好与清除仓储

- `GetLearningReportPreferences` 只读；未创建偏好返回关闭、七天、跟课、空章节、revision 0，不产生数据库行。
- `UpdateLearningReportPreferences` 校验周期/目标/章节和明确同意。开启要求目录及当前审核内容可用；仅调周期保持评价代次但重算下一自动时间；目标/范围变化递增代次、取消在途任务、将旧报告置 stale，保留既定自动时间。完全相同设置不改时间或代次。
- 同意版本当前 `v1`，证据入口要求匹配；版本过期不通过普通设置更新静默续订，需先关闭再明确确认。关闭撤销同意、清空自动时间、取消在途任务；旧派生数据仍可被进一步清除。
- `ClearLearningReports` 按既有 DELETE 契约同时关闭同意、递增代次、清除任务/快照及级联报告。保留偏好代次占位、原始作答和练习会话，不能凭旧租约晚写恢复。重复清除仍有效，不依赖会员服务或内容可用性。
- 所有变更首先锁定 owner/bank 偏好，再处理任务与报告；后续入队/租约/发布须遵循同一锁顺序。报告正文不可变，stale 是独立列，读取时不能忽略列状态返回旧正文。
- 这些 Service 方法不是公开鉴权接口。HTTP/worker 仍须绑定真实 owner，开启/读取/生成/发布仍须实时 lifetime 校验；只有关闭/清除不受会员撤销阻断。完整并发发布/清除测试须待任务与发布方法接线，不能以 Go race 检查替代数据库并发语义验收。

## 任务入队与去重（已完成仓储层；执行尚未接线）

- `QueueLearningReport` 在只读事务采集当前用户证据，随后以偏好 owner/bank 行为第一把写锁复核同意版本/代次、目标/章节、当前审核内容与题库版本；不把模型调用放入事务。任务 snapshot 内携带证据和服务端模型/提示词/判定策略版本，最终唯一 SHA 绑定这些因素；跨用户另由复合唯一键隔离。
- 手动入队不改 `next_due_at`，没有积分扣除或日额度；相同有效输入复用原任务/就绪报告。到期自动任务即使复用也只顺延下一周期。不同证据或配置的新任务取消同代次旧排队/运行任务；已完成报告暂保留，直到替代报告真正成功。
- 已失败/暂停任务在冷却后可重排，且仍使用不变的原始 snapshot；冷却中返回状态/剩余秒数。手动防滥用入口限流及调度器尚未接线，不要把去重当成限流或将低层 Service 方法暴露为公开 API。

## 任务租约与恢复（仓储层）

- `ClaimNextLearningReport` 先只读选取到期候选，再按偏好→任务行加锁，锁内重查 run_after/租约；核验同意、当前内容、不可变快照和最终版本指纹后授予唯一租约。旧租约超时先清 Token 并按尝试次数退避；最多自动授予 3 次，超限置 failed，不能靠并发候选读取绕过退避。
- `RenewLearningLease` 仅允许仍有效、未被撤销的租约续期，不缩短原期限；`FailLearningLease` 由当前有效 Token 提交失败，依尝试次数退避。权益依赖异常进入 paused，不自动调用模型；后续经过冷却且再次核验权益才可显式重排。真实权益仍待 worker/HTTP 接线，仓储测试合成失败不能证明外部校验已经完成。
- 发布函数、实时会员重检、模型超时及调度进程尚待实现；本层的成功认领不是模型服务已运行或报告已发布。
